# HKRSC TunMa Line Train Improvements (OpenBVE)
This is an improvement patch for the HKRSC Tun Ma Line train on OpenBVE.
It fixes bugs related to the driver’s cabin view, including view offset and display glitches, to deliver a more realistic driving perspective and better immersion.
Made for the HKRSC Tun Ma route, compatible with the original SP1900 train model. The original ATP and signalling logic remain unchanged, all MTR safety system simulations are preserved.
## HKRSC 屯馬線列車改進模組包（OpenBVE)
本模組為 OpenBVE 平台的屯馬線列車增強修復包，主要修復駕駛室視角相關錯誤，修正原有視角偏移、顯示異常等問題，還原更貼近真實的駕駛視野，提升駕駛沉浸感。
適配 HKRSC 屯馬線路線，相容對應 SP1900 列車車體，不改动原有 ATP、訊號系統邏輯，保留原版港鐵保安裝置的仿真設定。
